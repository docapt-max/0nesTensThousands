# 🎯 0nesTensThousands

An interactive, kid-friendly math practice web application designed to help children master **Hundreds (H), Tens (T), and Ones (O)** place values, expanded form matching, and 100-number grid puzzles.

---

## 🌟 Game Levels

### 📘 Level 1: Hundreds, Tens & Ones (Question 5)
- **Practice:** Break 3-digit numbers into Hundreds (H), Tens (T), and Ones (O) (e.g., `562 : 5 H, 6 T, 2 O`).
- **🔄 Infinite Practice:** Click the **"New Numbers"** button on the top-right to generate fresh random 3-digit numbers anytime.
- **Base-10 Blocks Visualization:** Toggle Base-10 blocks (Hundreds flats, Tens rods, and Ones cubes) to visualize numbers conceptually.
- **Smart Input:** Auto-advancing boxes with arrow key navigation and instant feedback.

### 🔗 Level 2: Match the Following (Question 6)
- **Practice:** Match Column A (Expanded Form like `300 + 40 + 5`) with Column B (Standard Number like `345`).
- **🔄 Infinite Practice:** Click the **"New Numbers"** button on the top-right for a brand new set of 5 random matching pairs.
- **Smooth Matching:** Click any item in Column A, then click its partner in Column B to connect them with animated colored lines.

### 🔢 Level 3: Fill the 100s Grid (Question 7)
- **Practice:** Complete a 10x10 number grid counting downwards in columns (e.g. Column 1: `501 to 510`, Column 2: `511 to 520`, ... Column 10: `591 to 600`).
- **🔄 Random Century Ranges:** Click **"Random Range"** to practice across any century:
  - `101 to 200`, `201 to 300`, `301 to 400`, `401 to 500`, `501 to 600`, `601 to 700`, `701 to 800`, `801 to 900`, `901 to 1000`.
- **Pre-filled Clues:** Based on authentic classroom worksheets with pre-filled landmark clues (`501`, `511`, `551`, `591`, `507`, `525`, `549`, `578`, `585`, `600`).
- **Touch Number Pad & Clues:** Includes a built-in touch keypad for tablets/smartphones and a **"Give Hint"** button.

---

## 🎮 Gamification & Features
- 🔊 **Synthesized Web Audio**: Built-in sound effects (pops, chimes, celebration fanfares) with mute toggle — no external audio downloads required.
- 🎊 **Confetti Cannon**: Celebratory particle animations upon completing rounds.
- ⭐ **Star Tracker**: Earn stars for correct answers, automatically saved in the browser (`localStorage`).
- 📱 **Fully Responsive**: Plays beautifully on laptops, desktops, iPads, tablets, and phones.

---

## 🚀 How to Run Locally

No installations or local servers needed!
Simply double-click `index.html` or open it in any web browser (Chrome, Edge, Safari, Firefox).
